# Калькулятор самолетиков + синтетические счета
полуавтоматизированный рассчет "самолетиков" и синтетических счетов

# Как пользоваться
скачать папку и открыть любой .html файл

# В чем разница samolet и sam-offline?
samolet.html - имеет внешние зависимоти для работы(нужен интернет для корректной работы CSS)

sam-offline - автономен. CSS стили скачаны и работает локально(при белых списках тоже)
